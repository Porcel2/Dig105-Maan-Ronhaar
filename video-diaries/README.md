### PPP Notes
* **Progress:** Chose the project and the name Kodu. Built the brand kit (logo, app icon, splash screens, colours and type), the competitor teardown and the customer journey map on Miro, and a working clickable prototype of both the expat and provider apps with onboarding, search and filters, provider profiles, quoting, escrow payment, translated chat, a provider calendar and earnings.
* **Problems:** The prototype grew faster than the research. Interview notes and the empathy maps still need to be written up in /documentation/. Hover based interactions did not work on touch screens and had to be rebuilt as tap based. Language matching had to be tightened so an A2 language is not counted as a shared language.
* **Plans:** Run the first user tests with three expats and two providers on the prototype, log them in /documentation/, and fix the top three things people get stuck on. Record the Sprint 2 diary on the results.
