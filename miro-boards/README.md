# Kodu Boards and Designs

## Miro
* [Kodu Design Mind Maps](https://miro.com/app/board/uXjVHhtk71o=/) - ten mind maps covering the essential considerations for an EU expat service app: GDPR, security, dual interfaces, payments, verification, translation, onboarding, trust, legal and architecture.
* [Competitor Teardown](https://miro.com/app/board/uXjVHhY24_E=/) - TaskRabbit and Yoojo as direct competitors, Facebook expat groups as the indirect one; feature matrix, review evidence, Unique / Better / Same / Poor analysis and the chosen niche angle.
* [Customer Journey Map](https://miro.com/app/board/uXjVHhd0FBY=/) - the expat journey from noticing a problem at home to a completed, paid and reviewed job, with goals, touchpoints, backstage, KPIs, positives, negatives and ideas per stage.

## Claude Design canvas
* [Kodu brand kit, components and screen mockups](https://claude.ai/artifact/9JVenrds5x967rkgt9PrnC) - 50 logo concepts, the chosen Mint home kit (logo system, app icon, colours and type, splash screens, store assets, animated splash and first screen), the prototype component library, sample data, and screen mockups for onboarding, search, provider profile.

## Prototype
* [Kodu clickable prototype](https://claude.ai/artifact/WMzbsRoT7fXTweao6BAQvq) - both the expat and provider apps, phone and desktop layouts. Same file as [`/prototype/index.html`](../prototype/index.html).

## Figma / FigJam
Not used in this project. Visual design was done on the Claude Design canvas and the prototype was coded directly.
